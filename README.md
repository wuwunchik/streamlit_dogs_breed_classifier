# 🐶 Определение породы собаки по изображению

Интерактивное веб-приложение на **Streamlit**, позволяющее определить породу собаки по загруженному изображению. Приложение использует модель глубокого обучения, обученную на **120 породах собак** из датасета [Stanford Dogs Dataset](https://www.kaggle.com/datasets/jessicali9530/stanford-dogs-dataset), и предоставляет краткую справку с **Википедии** на русском языке по определённой породе.

---

## 📌 Цели проекта

- 🧠 Построить точную модель классификации изображений собак по породам  
- 🌍 Предоставить пользователю описание породы и ссылку на статью в Википедии  
- 🌐 Развернуть удобный веб-интерфейс для работы с моделью  
- 🏷️ Обеспечить отображение названия породы на русском языке  

---

## 🚀 Как это работает

1. Пользователь загружает изображение собаки (jpg/png).
2. Изображение масштабируется до 224x224 и проходит предобработку.
3. Модель предсказывает одну из 120 пород.
4. Название породы переводится на русский язык (если перевод есть).
5. Выполняется запрос к Wikipedia API для получения краткой информации.
6. Интерфейс показывает:
   - Название породы (на русском)
   - Уверенность предсказания (в процентах)
   - Краткое описание породы
   - Ссылку на статью в Википедии (если найдена)
